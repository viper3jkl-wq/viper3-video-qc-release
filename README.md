# Viper3 · 本地视频质检与交付工作台

当前版本：**Viper3 v2.4**

Viper3 是一款在浏览器本地运行的视频质检、字幕校对与交付工具，集画面异常检测、SRT 校对、文稿匹配、NCM 转换、视频转码、五类交付版本导出和历史报告管理于一体。核心功能以单个 HTML 文件离线运行，素材不会主动上传到云端。

- [下载使用](#下载与运行)
- [Viper3 本地检测手册](docs/LOCAL_DETECTION_MANUAL.md)
- [完整版本更新日志](CHANGELOG.md)
- [发布文件 SHA-256](release-manifest.json)

> 本仓库是 **V2.4 公开发布库**，只提供加固后的单文件应用、使用文档、Logo 和发布哈希清单，不提供清晰维护源码、构建脚本或测试工程。应用内已嵌入可选 Whisper 本地识别服务包，无需另外下载服务源码。

## V2.4 更新内容

- 首次打开由使用者本人设置密码，之后每次打开均需验证。
- 使用 16 字节随机盐、600,000 次 PBKDF2-SHA-256 和 32 字节校验值，不保存明文密码。
- 连续错误触发递增锁定，锁定状态跨刷新保存，成功解锁后清零。
- 顶栏手动锁定、15 分钟无操作自动锁定、页面进入后台自动锁定。
- 锁定暂停音视频播放，但不主动取消检测或导出，也不清除素材与页面状态。
- 发布版对 14 个业务脚本进行选择性混淆，大型离线词典保持原样，避免不必要的体积与性能开销。
- 附带 `release-manifest.json`，用于核对 `index.html` 的 SHA-256。
- 修复重复锁定后的输入状态、异步验证期间切后台的锁定边界，以及错误密码提示被默认文案覆盖的问题。

**请注意**：本地密码锁不是服务端访问控制，代码混淆与哈希也不是绝对防破解或防复刻技术。修改 HTML、清理站点数据、复制文件或使用开发者工具仍可能绕过本地保护。请同时使用操作系统账户密码、磁盘加密和文件权限保护私人素材。

## 主要功能

### 画面异常检测

- 单个、批量或文件夹导入视频，检测黑帧、疑似夹帧和 PTS 连续性丢帧。
- 严格、均衡、宽松三种预设；FastEngine / WebCodecs 按媒体索引顺序解码，不以跳帧替代严格扫描。
- 支持 MP4 / MOV / MKV / WebM / TS，以及浏览器可解码的 H.264 / H.265 / AV1 / VP9 / VP8。
- 真实 FPS、异常时间码、帧范围、置信度、缩略图和逐帧复核。
- HTML / CSV / JSON / PDF 报告与断点续跑。

### 交付验收与音频体检

- ReelShort、DramaBox、ShortMax、TikTok、YouTube 和自定义规格模板。
- 检查分辨率、画幅、帧率、码率、时长、编码、音轨和首尾黑场。
- BS.1770 响度、真峰、静音、声道相关性和短时响度跳变检查。

### 视频转码与五类交付导出

- H.264、H.265、VP9、AV1；MP4、MOV、WebM、MKV。
- 分辨率、码率、快速模式、音频开关及 WAV / AAC 分轨。
- `01_成片`、`02_无字幕有音乐`、`03_字幕无音乐`、`04_声音分轨`、`05_字幕`。
- 当前组、全部组或勾选多组导出，多集共享 01–05 顶层目录并支持 ZIP。

### SRT 字幕校对

- SRT / TTML 批量导入，支持 UTF-8、UTF-16、GB18030。
- 英文大小写、拼写、空格、断句、缩写断行、行数与专名检查。
- 区分中英标点，独立建议句末 `.`, `?`, `!`，不与首字母大小写串联。
- 连续 `?!`, `!?` 及全角组合只保留一个问号；省略号和小写续句不强行补句号。
- 清理句首 `!`、`！”` 等跨字幕残留，采用建议后在原文下方显示完整字幕。
- 预览与修正版导出共用修改逻辑，原始字幕保持只读。
- SCC / SRT / TTML 当前文件或批量导出，支持帧率和显示方式设置。

### 文稿匹配与 GS 字幕版本

- 可选连接本机 `127.0.0.1` Faster-Whisper 服务，支持 small / large-v3 和本地模型目录。
- 页面可直接下载内嵌服务 ZIP，包含 macOS 与 Windows 启动脚本。
- 默认不连接服务、不加载模型；只有用户明确操作时才启动匹配。
- 逐句对齐、人工校对、多格式导出及 GS 指定敏感词替换。

### NCM 格式转换

- 本地批量转换有权处理的 NCM 为 MP3 / FLAC，不重新编码、不上传、不修改原文件。
- 1 MB 分块处理，支持标题、歌手、专辑、封面、单文件下载和 ZIP。

### 素材配对与界面

- 视频、字幕、人声、音乐、音效五槽位自动配对。
- 画面检测与 SRT 共用本地视频实例，支持同步定位与逐帧复核。
- Apple 风格浅色界面、历史报告、项目配置和版本记录。

## 下载与运行

### 方法一：下载 ZIP

1. 点击本仓库 **Code → Download ZIP** 并解压。
2. 使用最新版 Microsoft Edge 或 Google Chrome 打开根目录 `index.html`。
3. 首次打开时亲自设置密码，确认侧栏显示 **v2.4**。
4. 先用已知结果的短样本试跑，再执行正式批量任务。

### 方法二：Git 克隆

```bash
git clone https://github.com/viper3jkl-wq/viper3-video-qc-release.git
cd viper3-video-qc-release
```

然后使用浏览器打开 `index.html`。

核心功能不需要 Node.js、npm、Python、数据库或后端服务。只有主动使用 Whisper 文稿匹配时，才需要按页面说明下载并启动本地识别服务。

## 密码使用说明

- 密码为 14–128 个字符，同时包含大写字母、小写字母、数字和符号；首尾不能是空白字符。
- 第 5–9 次连续失败分别锁定 30 秒、60 秒、5 分钟、15 分钟、1 小时；第 9 次以后仍为 1 小时。
- 顶栏「锁定」可立即锁定；15 分钟无操作或页面进入后台也会自动锁定。
- 忘记密码没有页面内找回或一键重置入口，不要把密码通过聊天或共享文档发送给他人。
- 密码记录不跨浏览器、设备或页面来源同步。`file://` 与本地 HTTP 服务也属于不同存储环境。

## 发布文件校验

`release-manifest.json` 记录当前 `index.html` 的字节数和 SHA-256。Windows 可在发布目录执行：

```powershell
(Get-FileHash -Algorithm SHA256 .\index.html).Hash.ToLower()
```

将输出与清单中的 `sha256` 对比。该校验用于发现分发过程中的文件变化，不是远程可信证明。

## 已知限制

- 本地密码锁和混淆不是绝对防破解、绝对防复制或服务端级访问控制。
- 真实多集转码、五类 ZIP、音频、播放器与交付平台仍需完整生产回归。
- SCC 已通过文件格式检查，但达芬奇内部导入和短字幕 Pop-on 节奏仍需实机复核。
- TS 非常规封装可能错帧；ProRes / MPEG-2 需先转码，H.265 依赖系统解码器。
- 片尾淡出可能作为黑帧报告；SRT 句末类型是启发式建议，不能替代人工语境终审。
- NCM 已通过合成样本和浏览器字节级回归，真实非标准封装仍需抽检。
- Whisper 真实模型、真实音视频识别准确率及目标机器首次依赖安装仍需实机验收。
